功能

把每天要处理的事，摆在同一张桌面上

不折叠、不埋菜单，打开就是全部。少一次切换，就少一次走神。

两列清单，拖一下就好

今天要做的事放“今日办”，还没想好时间的丢进“待办池”。拖拽即可在两边流转，勾选完成原地保留痕迹。

便签是独立的小窗口

按 ⌘N 新建一张便签，它会以独立窗口浮在桌面上。随手记下想法，内容自动保存，创建和更新时间都看得见。

倒计时就是一根进度条

把正在进行的专注、会议或下班倒计时放到首页，剩余时间以真实宽度每秒平滑收缩，抬眼就知道还剩多少。

全局快捷键，随手唤起

不管在写代码还是看网页，⌘⇧H 唤回首页，⌘⇧J / ⌘⇧L / ⌘⇧I 直达对应模块。每个快捷键都能在首页点开重设。

直接打字，就能筛出来

首页顶部的搜索框会同时过滤今日办、待办池和便签，匹配内容高亮显示。按 Esc 立刻清空，回到完整视图。

没有账号，数据就在本机

日程、便签和设置以 JSON 保存在本地目录，不经过任何服务器。支持一键备份、恢复、导出和导入。

还有
  • 深色 / 浅色主题
  • 首页模块按需隐藏
  • 文件模式快捷操作

快捷键

你的手不用离开键盘

默认组合键已经排好，也可以点击首页上对应模块的快捷键标签，录下自己顺手的那一组。如果组合键被其他应用占用，换一组就能生效。

除新建便签外，其余组合键都可以自定义。

唤回主窗口 ⌘⇧H
打开今日办 ⌘⇧J
打开待办池 ⌘⇧L
打开倒计时 ⌘⇧I
新建便签 ⌘N
清空搜索 Esc

本地与 AI

数据留在本机，能力可以外接

默认完全离线可用；需要时，再打开 MCP 服务，把日程交给 AI 客户端读写。

本地优先

没有注册、没有同步、没有遥测。

~/Library/Application Support/schedule-pro/appdata
├─schedule.json今日办
├─inspiration.json待办池
├─sticky*.json便签内容
├─shortcuts.json快捷键
└─settings.json偏好设置

设置页提供备份、恢复、导出与导入，换电脑时整包带走即可。

MCP 服务（可选）

让 AI 客户端读懂并更新你的清单。

  1. 1在设置中启动 MCP 服务，本地地址只在运行时监听。
  2. 2复制生成的客户端配置，粘贴到任意支持 MCP 的 AI 客户端。
  3. 3之后就能让 AI 读写今日办、待办池、倒计时和便签。
  4. 4服务只监听 127.0.0.1，局域网内的其他设备无法访问。

服务默认关闭，是否开启完全由你决定；关闭后客户端需要重新连接。
